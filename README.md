# チーム戦デッキビルダー

遊戯王OCG 日本選手権チーム戦のルールに合わせて、チーム 3 人分のデッキを同時に組むための Web アプリです。

## できること

- 3 デッキ（A / B / C）のメイン・エクストラ・サイドを同時に編集
- デッキをまたいだカードの移動（ドラッグ＆ドロップ、またはカード詳細の「〇・メインへ」ボタン）
- 遊戯王ニューロン（公式カードデータベース）のカード検索
  - カード名 / テキスト / ペンデュラム効果 / カードNo、カード種類、属性・種族・モンスターの種類・魔法罠の種類、並び順
- チーム内の同名カード枚数制限
  - 同名カードはチームの 3 デッキ合計で 3 枚まで（制限 1 枚・準制限 2 枚・禁止 0 枚）
  - メイン・エクストラ・サイドをすべて数えます
  - 禁止・制限リストはニューロンから最新のものを取得
- ニューロンのデッキコード、または公開したデッキの URL からインポート（非公開のデッキはブックマークレットで）
- 禁止・制限・準制限は、公式のカードデータベースと同じ色と形のマークで表示
- ニューロンのデッキ画像から登録（カードの絵柄で照合し、確認画面で直してから登録）
- ルーム: URL を共有したメンバーと 3 デッキを同時に編集（公開版のみ）
- デッキごとにカードへタグ（「誘発」「初動」など）を付け、初手 5 枚にタグの付いたカードが何枚来るかを 1 万回のシミュレーションで表示
- テキスト出力、ファイルへの保存・読込、元に戻す / やり直す（Ctrl+Z / Ctrl+Y）
- 編集内容はブラウザに自動保存

## 起動方法（ローカル）

Node.js 18 以上が必要です（追加のパッケージは不要）。

```bash
npm start
```

ブラウザで http://localhost:8787 を開きます。ポートは環境変数 `PORT` で変えられます。

ニューロンはブラウザから直接読み込めない（CORS）ため、`server.js` が検索・禁止制限リスト・デッキ・カード画像を中継します。

## 画像から登録

「画像から登録」で、ニューロンのデッキ画像（メイン・エクストラ・サイドの一覧画像）とデッキのテーマ（例: ラビュリンス）を入れると、次の手順で照合します。外部の AI サービスは使わず、画像の処理はすべてブラウザ内で行います。

1. 見出しの線と 10 列の並びから、カードを 1 枚ずつ切り出す（並んでいる同じカードはまとめて枚数にする）
2. テーマで見つかる最近の公開デッキ 12 個と、テーマを問わない最近の公開デッキ 10 個に入っているカード、カード名にテーマを含むカードを候補にする
3. 切り出したカードと候補のカード画像の絵柄を見比べ、いちばん近いカードを選ぶ

カード名の文字は小さすぎて読めないため、絵柄だけで照合しています。候補に入っていないカードや、候補と違うイラストのカードは「未確定」になるので、確認画面で名前を入れて探してください。探した結果は絵柄の近い順に並び、イラスト違いも見比べます。

## タグと初手シミュレーション

デッキのカードをクリックし、詳細欄の「タグ」に名前を入れて Enter で付けます（1 枚に 8 個まで）。「初動」「組み合わせ初動」「誘発」「ドロー系」の 4 つと、ほかのカードで使ったタグはボタンで付けられます。タグはデッキごとに別々で、同じカードでもデッキ A とデッキ B で違うタグにできます。

「ドロー系」を付けたカードは、詳細欄でドロー枚数（1〜10 枚、既定は 2 枚）を指定できます。初手シミュレーションでは、手札のドロー系を使ってその枚数だけ追加で引き、引いたカードにドロー系があれば続けて使います。ほかのタグはすべて追加で引いた分を含めた手札で計算し、初手 5 枚だけの値を「ドローなし」として並べます。同名のドロー系は既定では 1 ターンに 1 枚だけ使います（結果画面のチェックで、すべて使う計算に切り替えられます）。コストや発動条件は考えません。

デッキの見出しの「初手」で、メインデッキからランダムに 5 枚引く試行を 1 万回行い、次を表示します。

組み合わせ初動は、2 枚以上引いたら（同名の 2 枚でも）そろったとして、すべての計算に使います。ほかのタグは 1 枚以上でそろったとします。

- **初動で動ける割合**（「初動」か「組み合わせ初動」を付けたとき）: 初動 1 枚以上、または組み合わせ初動 2 枚以上で動けた割合と内訳。組み合わせ初動で動けた手札のうち、引いた組み合わせ初動がすべて同名だった割合も表示します
- **動けて、さらにほかのタグもある割合**: 初動に使ったカードとは別に、「誘発」などのタグのカードを 1 枚以上持っていた割合（タグごと）
- **タグの組み合わせ**: タグ 2 つのカードを、別々のカードでそれぞれ必要な枚数ずつ引いた割合（すべての組み合わせ）
- **タグごと**: タグの付いたカードを 0〜5 枚引いた割合と回数、そろった割合（組み合わせ初動は 2 枚以上、ほかは 1 枚以上）。2 枚以上引いたときに同じカード（同名）を重ねて引いていた割合と、カードごとの同名の重複率

1 枚で複数のタグを持つカードは、組み合わせの計算では 1 つの役割にしか数えません。

## ルーム（同時編集）

「ルーム」→「ルームを作成」で、今の 3 デッキを最初の内容にしたルームができ、共有 URL（`?room=…`）が発行されます。URL を開いたメンバー全員が同じ 3 デッキを同時に編集でき、チームの採用枚数の制限も全員の変更を合わせて効きます。

- 変更は「デッキ・枠・カードごとの枚数」単位で送るので、別々のカードを同時に編集してもどちらも残ります（同じカードの枚数を同時に変えた場合は、後に届いた方になります）
- 通信が切れても自動でつなぎ直し、切れている間の変更はつながってから送ります
- 参加中は手元のデッキ（ブラウザの保存）を上書きしません。ルームを出るときに、ルームのデッキを手元に残すか選べます
- ほかの人の変更が届くと、「元に戻す」の履歴は消えます（ほかの人の変更まで戻してしまわないため）
- 30 日間変更のないルームは自動で削除されます

ルームは Cloudflare の Durable Objects（`src/room.js`）で動くため、`npm start` のローカルサーバーでは使えません。手元で試すときは `npx wrangler dev` を使います。

## コナミのサーバーへの負担を抑える仕組み

カード検索・禁止制限リスト・デッキ・カード画像は、遊戯王ニューロン（公式カードデータベース）から読み込みます。負担をかけないよう、次のようにしています。

- **キャッシュ**: 読み込んだ結果は、実行インスタンスのメモリと、Cloudflare の共有キャッシュ（Cache API。同じデータセンターの利用者全員で共有）に入れ、同じものを何度も取りに行かないようにしています。保持する期間は、カード画像 30 日、イラスト違い 7 日、画像照合の候補・禁止制限リスト 6 時間、カード検索 1 時間、デッキ 2 分です。ブラウザにもカード画像を 30 日キャッシュします
- **同時アクセスの上限**: コナミのサーバーへは、同時に 4 リクエストまでしか送りません。「画像から登録」でブラウザが候補の画像を読むのも、同時に 4 枚までです
- **画像照合の候補の量**: 候補に使う公開デッキは、テーマで 10 個、最近のもの 8 個までです
- **回数の上限**: 同じ IP からのリクエストは、10 分で 3000 回までにしています
- **名乗り**: リクエストには、このツールの名前とリポジトリの URL を入れた User-Agent を付けています

## 公開する場合（Cloudflare Workers）

`worker.js` と `wrangler.toml` を同梱しています。静的ファイルと中継 API を 1 つの Worker で配信できます。

```bash
npx wrangler deploy
```

## インポートできるデッキ

「ニューロンからインポート」に、次のどちらかを入力します。

- ニューロンで発行した**デッキコード**（英数字 7 文字。例: `1sgb47h`）。デッキ検索でコードのデッキを探し、検索結果のリンク（デッキコード付き）から読み込みます。デッキコードがあればログインなしで見られるので、**非公開のデッキも読み込めます**
- ニューロンの「マイデッキ」で**公開**にしたデッキのページの URL

```
https://www.db.yugioh-card.com/yugiohdb/member_deck.action?ope=1&cgid=xxxxxxxx&dno=1
```

### 非公開のデッキ

非公開のデッキは、ニューロンでデッキコードを発行して入力するのがいちばん手軽です。デッキコードを発行しない場合、非公開のデッキはログインした本人しか見られないため、サーバーからは読み込めません。そのときはブックマークレットを使います（ログイン情報やデッキの内容はこのツールのサーバーを通りません）。

1. 「ニューロンからインポート」→「非公開のデッキを読み込む」の「チーム戦デッキへ送る」ボタンを、ブックマークバーにドラッグして登録する
2. PC のブラウザでニューロンにログインし、読み込みたいデッキのデッキレシピ画面を開く
3. 登録したブックマークを押すと、このツールが開いてデッキを受け取る（読み込み先を選んで「読み込む」）

ブックマークレットは、画面に表示されているデッキ（カードの cid・枚数・名前・種類・画像）を読み取り、このツールの URL の `#deck=` 以降に入れて開くだけです（`public/bookmarklet.js`）。スマホのアプリで作ったデッキは、デッキ画像を保存して「画像から登録」でも読み込めます。

## 構成

| ファイル | 内容 |
| --- | --- |
| `public/` | 画面（HTML / CSS / JS、ビルド不要） |
| `src/konami.js` | ニューロンの HTML の取得と読み取り |
| `public/deckimage.js` | デッキ画像からのカードの切り出しと絵柄の照合 |
| `public/handsim.js` | 初手シミュレーション |
| `public/bookmarklet.js` | 非公開デッキをニューロンの画面から送るブックマークレット |
| `public/roomsync.js` | ルームでやりとりする変更の形（ブラウザとサーバーで共通） |
| `src/room.js` | ルーム 1 つ分のサーバー（Durable Object） |
| `src/api.js` | `/api/search` `/api/limits` `/api/deck` `/api/pool` `/api/arts` `/api/img` |
| `server.js` | ローカル用サーバー |
| `worker.js` | Cloudflare Workers 用の入口（`/api/room/*` をルームへつなぐ） |

ニューロンのページ構成が変わると、`src/konami.js` の読み取り部分の修正が必要になります。
